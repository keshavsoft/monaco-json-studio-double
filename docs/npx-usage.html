CLI (npx) Usage

Run monaco-json-studio-double directly from the terminal without cloning.

Commands

npx monaco-json-studio-double
npx monaco-json-studio-double file-picker status
npx monaco-json-studio-double select stats

Generates ./monaco-double-<header>-<footer> and automatically appends -1, -2, ... so previous studios stay intact.
