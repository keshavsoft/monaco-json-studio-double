Why monaco-json-studio-double Exists

2-pane static Monaco JSON Studio generator composing base-header, base-body (double), and base-footer.

Design Story

Comparing two JSON payloads or pairing input data with a transformation spec requires two side-by-side Monaco panes under one clean header and footer.

monaco-json-studio-double composes base-header, base-body (double), and base-footer with active-pane tracking so top-bar actions automatically apply to whichever pane you focused.
